## MiO 能做什么

|  |  |
|---|---|
| 🔁 **把你的歌单带走** | 支持从 Spotify、YouTube、哔哩哔哩、网易云音乐、QQ 音乐和酷狗导入。每一条匹配都会先给你看——你不点确认就不会下载 |
| 🎧 **好好地播放它们** | 锁屏与蓝牙控制、带随机和循环的播放队列、交叉淡入淡出、十段均衡器、音量均衡和睡眠定时器 |
| 💾 **把它们留在手机里** | 音乐、歌单和曲库都是你设备上的文件。没网也能听，会员到期也不会消失 |
| 📤 **搬到你的下一台手机** | 把曲库导出成一个文件，在新手机上载入 |
| 🌍 **说你的语言** | English、简体中文、Español、Français、日本語、한국어、Русский |
| 🔒 **什么都不向你要** | 没有账号，没有广告，没有追踪，没有付费档 |

## 安装

1. 点上面的**下载安卓版**，下载完成后打开这个文件。
2. 安卓会问要不要允许从你的浏览器安装应用，措辞可能是*「安装未知应用」*。允许一次即可。
3. 点**安装**，然后打开 MiO。

**安卓会向你发出警告，而这个警告是对的。** MiO 不来自应用商店，所以你的手机没有办法
为它背书。这是预期之内的，没有出任何问题。MiO 不在 Google Play 或 App Store 上，以后
也不会——这两个商店都禁止它所做的事。

**运行条件：** Android 7.0（Nougat）及以上，任意手机均可——64 位和 32 位 ARM 都包含
在内。下载约 69 MB，另外还需要放你添加的音乐的空间。

用新版覆盖安装旧版**会保留你的曲库**，不需要先卸载。

## 更新

大多数修复会自己送达：MiO 在启动时检查，在后台下载，下次打开时生效。你什么都不用点。

偶尔有的改动需要一个全新的 APK。到那时应用会告诉你，文件也会在这里。

## MiO 不做什么

- **它不卖任何东西。** 没有付费档，没有解锁项，也没有只给赞助者的功能。即便有捐赠，
  也不会因此获得任何东西。
- **它不会把你的曲库、你听了什么或者你是谁发送到任何地方。**
- **它不在用户之间传播音频。** 每台手机都自己去取。

## 有什么不好用？

在应用里打开**设置 → 诊断**，点**复制报告**，然后通过那个页面上的反馈表单发出来。
报告的内容是应用记录的自身运行情况——不含歌曲名，也不含任何个人信息。
